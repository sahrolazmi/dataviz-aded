# Charts That Guide Action

Azmi Noteworthy Series: a self-study website on data visualisation and graphical presentation, for the Advanced Diploma in Applied Epidemiology in Disease Control and Outbreak Management (ADED).

Live site: https://sahrolazmi.github.io/dataviz-aded/

The site is one file, `index.html`, with no build step. Charts marked "illustrative" use made-up numbers for teaching.
